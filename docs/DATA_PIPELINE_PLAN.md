# A股历史数据仓库实施计划

> 目标：首次获取2018年至今尽可能完整的A股历史数据，固化为版本化本地快照；选股和回测只查询本地数据，不在回测过程中访问外部接口。

## 当前状态

- 项目：`stock-lab`
- 分支：`master`
- 免费数据源：东方财富公开行情接口（无需 Token，无稳定服务承诺）
- 高完整度数据源：Tushare（当前尚未配置 Token）
- 首个快照代号：`CN_A_20180101_<获取日>_v1`

## 第一阶段实际可获取字段（东方财富）

每只当前上市股票从2018年至今：

- 交易日期
- 开盘、收盘、最高、最低
- 成交量、成交额
- 振幅、涨跌幅、涨跌额
- 换手率
- 股票代码、名称、市场和上市日期（接口可用时）

第一阶段不把实时计算得到的均线、MACD、RSI等派生指标落库；回测时从原始日线计算。

## 第二阶段需要 Tushare 的数据

- 退市股票和历史证券状态
- 精确复权因子
- 每日PE/PB/PS/股息率、股本和市值
- 停复牌、涨跌停、名称与ST变更
- 财务报表、财务指标及公告日期

Tushare Token 只允许放在本地或服务器 `.env`，不得提交Git，也不要发送到聊天。

## 数据安全与可复现性

1. 回测请求必须记录 `data_version` 和 `strategy_version`。
2. 已发布快照只读，不原地覆盖；修正数据时生成新版本。
3. 回测某日只能使用该日收盘前已经公开的数据。
4. 退市、ST、停牌股票不得从历史股票池中事后删除。
5. 外部接口中断时允许继续使用最近一次成功的本地数据。
6. 下载任务必须限速、低并发、可恢复，不对公共接口发起突发请求。
